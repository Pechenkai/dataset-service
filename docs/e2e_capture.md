# Имитация E2E-сценария и снятие трафика

Документ описывает, как вручную повторить пользовательский сценарий из `TestE2E_PublicDatasetJourney` и зафиксировать сетевой трафик для предъявления преподавателю.

## Инструменты

- **Postman** — удобно держать цепочку HTTP-запросов (импортируйте запросы из раздела ниже или создайте свою коллекцию).
- **Wireshark** (подойдёт любой сниффер: tcpdump, mitmproxy) — фильтр `tcp.port == 8080` позволяет увидеть все обращения к REST API.

## Подготовка окружения

1. Поднимите инфраструктуру, которая используется в интеграционных тестах:

   ```bash
   docker compose up -d db minio
   ```

2. Примените миграции и запустите API, который слушает `:8080`:

   ```bash
   go run ./cmd/api
   ```

3. Очистите локальные сессии: в Postman откройте Cookies → `localhost` → Remove All. Это гарантирует, что набор запросов выполняется от «чистого» пользователя.

## Последовательность запросов (Postman)

Используйте базовый URL `http://localhost:8080`. Тела запросов соответствуют тестовым фабрикам и не требуют авторизации.

1. `GET /categories` — убеждаемся, что справочник доступен.
2. `POST /reviews`
   ```json
   {
     "user_id": 2,
     "dataset_id": 7,
     "rating": 5,
     "text": "Great dataset for prototyping models"
   }
   ```
3. `GET /datasets?public=true` — проверяем выдачу публичных датасетов.
4. `GET /datasets/7/versions` — запрашиваем версии созданного датасета.
5. `POST /subscriptions`
   ```json
   {
     "user_id": 2,
     "dataset_id": 7
   }
   ```

Каждый запрос добавляйте в Postman-коллекцию, запускайте их по порядку и убедитесь, что статусы совпадают с ожиданиями (200/201/204).

## Снятие трафика в Wireshark

1. Запустите сбор на интерфейсе, через который идёт трафик к `localhost` (обычно `lo`), с фильтром `tcp.port == 8080`.
2. Переключитесь в Postman и выполните всю последовательность запросов.
3. Остановите захват, воспользуйтесь `Follow HTTP stream` для каждого запроса и экспортируйте содержимое в текстовом виде.
4. Конкатенируйте экспортированные куски в файл `logs/e2e_capture_example.txt` — именно так сформирован артефакт из репозитория.

## Артефакты

- `logs/e2e_capture_example.txt` — пример захваченного трафика (Postman + Wireshark). При необходимости обновите файл новым сценарием и закоммитьте вместе с отчётом.

После демонстрации окружение можно свернуть:

```bash
docker compose down -v
```
